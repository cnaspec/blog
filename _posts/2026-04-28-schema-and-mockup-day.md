From the schema presentations, it was clear that ours was based too closely on the Excel spreadsheet we were given access to. It would have been functional, but it would have offered no real benefit over the Excel spreadsheet, so we are going to need to break the problem down into lots of entities. We should also consider how we can use the structure to prevent data entry mistakes.

With the mockups, we used Moqup and work was divided evenly between each person to make sure everything was done by the deadline. I think it looked really good, but whilst presenting realised that because we had worked on all our pieces separately we hadn't considered how each page would interact with the others and there were few buttons which broke the immersion of the preview. I need to go back and add more navigation buttons to the other pages.

To be honest, we did these a while ago and I forgot to write the blog post so I don't really remember anything else. I did go back and add the buttons and a few additional pages to make it more complete in case we decided to show it to the clients during our second meeting.
